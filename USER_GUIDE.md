# LeseStufe AI User Guide

Open the application at:

https://lesestufe-ai.onrender.com

## Read a book

1. Choose a book from the book selector at the top.
2. Select your German level: A1, A2, B1, B2, or C1.
3. Read the page. Highlighted words are words above your selected level.
4. Use the page controls to move between pages.

## Understand a word

Click any highlighted German word. The popover can show:

- English meaning
- CEFR level
- Word type and grammatical gender when available
- German pronunciation
- Save to Flashcards

Translations use the built-in vocabulary dictionary first, then Gemini or DeepL for words that are not already known.

## Download vocabulary

1. Click **Vocabulary PDF** in the top bar.
2. Wait for the PDF to be generated.
3. Open the downloaded PDF to review German words, English meanings, levels, and page context.

## Flashcards

Click the bookmark icon on a word or choose **Save to Flashcards** in the word popover. Open **Flashcards** from the top bar to review saved words and track progress.

## Learning tools

- **Tutor:** Ask questions about the current page or difficult German expressions.
- **Grammar:** Select a sentence to see grammar and case explanations.
- **Quiz:** Practice saved vocabulary with generated questions.
- **Placement test:** Answer diagnostic questions to estimate your starting level.
- **Level shifter:** Rewrite a passage in a simpler German level.

## Scanned PDFs

Image-only PDFs may need OCR. Upload the PDF and wait for processing. If no readable text is found, use the paste-text option and provide the German text directly.

## Troubleshooting

- If the page is slow at first, the free hosting service may be waking up.
- If an unknown word has no meaning, refresh the page and try again later.
- The app owner manages the translation services and API keys. Users do not need to enter an API key.
